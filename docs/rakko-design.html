01页面结构约定

当前稿件只包含 / 与 /chat 两个路由；每个路由是一个独立、完整的页面稿，且都带系统级标题栏。各路由的网格列数、顶部区域与内容互不共享，新增路由 = 新增一个独立的 route 区块。

  • 系统标题栏（窗口级） — 位于外框最顶部、卡片之上：应用 logo（π）+ 应用名 + 右侧最小化 / 最大化 / 关闭三枚窗口按钮；关闭按钮悬停变红底白字，为 Windows 桌面应用惯例；标题栏整条可视为拖拽区，不参与页面内容排版。
  • 一路由一稿 — 每个路由在自己的外框（Frame）里完整呈现，含 Dock、主卡与该页专属的一切区域；页面稿之间不共享顶部区域，只共享 token。
  • 顶部区域自选 — / 首页无卡片工具条，内容顶格；/chat 对话顶部是会话标题栏：置顶图钉 + 会话名称 + 状态点紧贴标题之后 + ⋯ 更多按钮；侧边栏开关靠右。页面内标题区域不再重复页面名（如自动化曾有的顶部标题已移除）。
  • Dock 图标语义 — 首页 house / 对话气泡 / 自动化计时器（秒表） / 搜索 / 子代理 / 插件；下方独立胶囊放通知铃铛与账号头像。激活态为墨黑底反白。
  • OpenUI 界面回复 — Agent 的回复可以是内嵌的交互界面块（表单 / 数据卡 / 图表…），头部带 OPENUI 黄标 + 组件名 + 源码 / 新窗口操作。
  • composer 权限档位 — 输入条左侧为权限 pill（当前「完全访问」为橙色警示态），点击弹出四档菜单：默认权限 / 允许编辑 / 自动审批 / 完全访问（当前项带勾选）；右侧为模型 chip、麦克风与发送键。首页与对话页 composer 同构。
  • 侧栏收起 = 内容撑满 — 对话页默认两列；点开关展开后第三列才加入网格，收起时主卡撑满容器。
  • 右卡等高 · 多 tab — 展开时右卡与主卡等高（无顶部留白），内部多 tab：概览 / 审查 / 终端 / 文件，各 pane 独立滚动。
  • 唯一硬约束 — 内边距节奏统一 26px（--pad 变量）。

03共享设计 token

跨路由只共享这些 token；除此之外各页面自由设计。

  • 内边距 — --pad: 26px：主卡内容区、标题栏、composer、右卡全部引用同一变量。
  • 三层底色 — 画布 #E9E9E6 → 外框内衬 #F3F3F0 → 卡片 #FDFDFB（深色模式自动切换）。
  • 强调色 — 酸性黄 #ECF24D「活跃 / 可执行」；墨黑 #17181A pill / 发送键 / 激活态；橙 #E8590C 权限警示；红 #E03131 危险与窗口关闭悬停。
  • 窗口按钮 — 42×32 圆角 9，默认无底色；最小化 / 最大化悬停浅灰，关闭悬停红底白字。
  • 图标 — 统一 1.8px 线性描边、圆头端点；窗口控制专属 i-minus / i-max / i-x，自动化用 i-timer 秒表造型；禁止借用语义不符的图标。
  • 字体 — 无衬线主体；Georgia 衬线仅作小标签点缀。
  • 圆角与描边 — 外框 38 / 卡片 30 / 控件 10–16；1px 描边 --line。
